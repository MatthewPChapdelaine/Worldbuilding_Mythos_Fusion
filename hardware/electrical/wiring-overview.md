# Wiring Overview

## Connector convention

| Class | Connector | Notes |
| --- | --- | --- |
| E-stop | 2-wire screw terminal | Red loop, normally closed |
| Battery | XT90 or equivalent | Ampacity and polarity verified |
| Servo | JST-PH or screw terminal | No mixed 5 V/logic connectors |
| Data | CAT6/Screw | Data and power not mixed |
| USB | USB-C | Service only |
