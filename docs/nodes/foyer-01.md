# Foyer Greeter: Node 01

## Form

- Life-size upper and lower standing mannequin
- Weighted wheeled base
- Locking casters
- 14-DoF face/neck plus gesture arms
- First build excludes bipedal walking

## Trigger

- Doorbell webhook
- Front-door motion sensor
- Home Assistant presence

## Safety state

- Head down to sleep angle
- Eyes closed
- Arms at dolly pose
- Servo relay deenergized
